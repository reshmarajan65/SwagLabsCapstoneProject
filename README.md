# SwagLabs – Manual & Automation Testing

## Project Overview

SwagLabs (SauceDemo) is a web application tested using manual and automation testing techniques.

## My Role

**Manual & Automation Tester**

* Prepared Test Plan, RTM, and manual test cases
* Performed Functional, Positive/Negative, Boundary, Validation, Navigation, and Exploratory Testing
* Identified and documented defects
* Automated key application workflows using Selenium WebDriver
* Developed automation scripts using Java, TestNG, and Page Object Model (POM)
* Implemented data-driven testing using Excel and TestNG DataProvider

## Testing Scope

Login, Products, Cart, Checkout, Common Features, Navigation, Validation, and Application State.
